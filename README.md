# NextVision — ระบบวิเคราะห์วิดีโอสำหรับสาธิตลูกค้า

เว็บแอปที่ทำงานจริง (ไม่ใช่ภาพจำลอง) ให้ Operation อัปโหลดคลิปกล้องวงจรปิด วาดโซนหรือเส้นนับบนภาพ แล้วดูผลการตรวจจับคนและยานพาหนะพร้อมกรอบบนวิดีโอ ถามระบบเป็นภาษาไทย และส่งออกเหตุการณ์เป็น CSV

โครงสร้างผู้ใช้เหมือน NextOCR: **Operation** เห็นเฉพาะคลิปของตัวเอง · **MD** เห็นและแก้ได้ทุกคลิป · **Admin** จัดการผู้ใช้/ตั้งค่า/ดูบันทึกการใช้งาน

## ทำอะไรได้ตอนนี้

| โมดูล | สถานะ |
|---|---|
| นับและติดตามคน / ยานพาหนะ (รถ รถจักรยานยนต์ รถบัส รถบรรทุก จักรยาน), แผนที่ความหนาแน่น | พร้อมใช้ |
| โซนหวงห้าม / เฝ้าดู พร้อมเตือนเมื่อเข้า และเมื่ออยู่นานเกินกำหนด | พร้อมใช้ |
| นับข้ามเส้น (ทิศตามลูกศร / ทิศตรงข้าม) | พร้อมใช้ |
| เตือนคนหนาแน่น | พร้อมใช้ |
| ถามระบบภาษาไทย (ตอบจากผลวิเคราะห์ที่บันทึกไว้เท่านั้น) | พร้อมใช้ |
| ตรวจ PPE, จดจำใบหน้า, อ่านป้ายทะเบียน | **ยังไม่เปิด** ดู "เพิ่มโมดูล" |

ตัวเลขทุกตัวคือ "สิ่งที่ระบบติดตามได้ในคลิปนั้น" ไม่ใช่ตัวเลขความแม่นยำ อย่าอ้างความแม่นยำกับลูกค้าก่อนทดสอบกับภาพจริงของเขา

## ทำงานอย่างไร

```
Browser ──upload──▶ Node/Express ──▶ Postgres (ผู้ใช้, คลิป, เหตุการณ์, keyframe)
                        │
                        └─ คิวงาน (ทีละงาน) ─▶ worker/analyze.py
                              prepare : ffprobe → ffmpeg ย่อเป็นไฟล์ดูในเว็บ (≤960px) + ภาพตัวอย่าง
                              analyze : YOLOX-Tiny (onnxruntime, CPU) → tracker (IoU + ความเร็ว, 2 ขั้น)
                                        → กฎโซน/เส้น/คนหนาแน่น → result.json + keyframe
```

- ไฟล์ต้นฉบับถูกลบหลังแปลงเสร็จ เก็บเฉพาะไฟล์ที่ย่อแล้ว ภาพเหตุการณ์ และผลวิเคราะห์ ผู้ใช้ลบคลิปของตัวเองได้ทุกเมื่อ
- ตัวตรวจจับ YOLOX (Apache-2.0) ส่วน tracker และกฎเหตุการณ์เป็นโค้ดที่เขียนใหม่ในโปรเจกต์นี้ ดู `NOTICE.md`
- ไม่ได้ใช้โค้ดหรือโมเดลจาก `CU-DrAgon/rocm-cctv-analysis` (PolyForm Noncommercial ห้ามใช้เชิงพาณิชย์)

## รันในเครื่อง

```bash
# ต้องมี Node 22+, Python 3.10+, ffmpeg
python3 -m venv .venv && . .venv/bin/activate && pip install -r worker/requirements.txt
sh scripts/get-model.sh            # ดาวน์โหลด YOLOX-Tiny และตรวจ checksum
npm install
PYTHON_BIN=$(which python) BOOTSTRAP_ADMIN_USERNAME=admin BOOTSTRAP_ADMIN_PASSWORD='ตั้งรหัสเอง-10ตัวขึ้นไป' npm start
# เปิด http://localhost:8080
```

ไม่ตั้ง `DATABASE_URL` ระบบใช้ Postgres แบบฝัง (PGlite) เก็บใน `DATA_DIR` เหมาะกับทดลองเครื่องเดียว

## ทดสอบ

```bash
npm test                                            # API ทั้งหมด ใช้ worker จำลอง ไม่ต้องมี Python
E2E_CLIP=/path/to/short.mp4 npm run test:e2e        # เบราว์เซอร์จริง + worker จริง + ภาพหน้าจอใน e2e-out/
```
